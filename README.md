# customgotchi
oh yeah baby tamagotchi time

... but this time serving looks


i made this project because my introduction to hardware was putting a new battery into my old angelgotchi with an iFixit kit and a CR2032 battery i stole from my dad's SNES cartridge repair stash. I got to learn to repair consoles and solder because of that experience.

i'm still really new to hardware, and i figured what better to make than a tamagotchi?

much like a real tamagotchi, you use the three buttons to raise and care for your virtual pet!
